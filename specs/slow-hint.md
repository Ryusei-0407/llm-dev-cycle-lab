# Feature: slow-hint

ストリーミング応答が長引いたとき、ユーザーに「応答に時間がかかっています…」と
知らせる。無反応に見える時間を減らすためのUX機能。

## ユーザーストーリー

- ユーザーとして、応答が長引いているとき「壊れた」のか「時間がかかっている」のか
  区別できる表示がほしい

## 公開インターフェース

- ストリーミング開始から **10秒** 経過しても完了していない場合、
  `data-testid="slow-hint"` の要素を表示する
- ストリーム完了・停止・エラーのいずれでも即座に消える
- 10秒未満で完了した場合は一度も表示されない

## テスト観点とレイヤ

- 実タイマー(10秒)に依存するため、**Playwright Clock API でのみ決定的にテスト可能**。
  Vitest Browser Mode の fake timers はページロード後のパッチであり React の
  スケジューラと干渉しうるため使わない
- → **Playwright Component Testing**(`e2e/components/slow-hint.spec.ts`)で
  `page.clock.install()` + `fastForward(10_000)` により検証:
  - 正常系: 10秒経過で表示 → ストリーム完了で消える
  - 失敗系は専用UIなし(既存のエラーバナーに委譲)のため対象外
- E2E(フルページ)には追加しない: コンポーネント層で十分であり、
  E2E本数上限(正常1+失敗2)を消費しない
